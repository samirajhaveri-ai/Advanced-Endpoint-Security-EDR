# Advanced Endpoint Security (EDR)

Advanced endpoint detection and response project.

## Repo setup

- **Design skills**: The [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) skill suite is installed under `.claude/skills/` and loads automatically in Claude Code sessions for UI/UX work.
- **Push notifications**: An hourly monitor watches all branches and sends a WhatsApp alert (via Zapier) when new commits land, with email fallback.
